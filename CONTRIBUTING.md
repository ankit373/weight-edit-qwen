# Contributing

This repo is the record of a finished study, so the scripts stay as they were run. Their hashes are in `SCRIPTS.md`.

Issues are welcome, especially if a script does not run, a number does not match the paper, or a path is wrong. Please say which file and which table.

Pull requests that change a script under `scripts/` will usually not be merged, because the published numbers came from these exact files. Fixes to the README and other docs are fine.
